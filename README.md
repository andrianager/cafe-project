# ☕ Cafe Aroma

პრაქტიკული პროექტი (მოდული 06.1.1.9) – Front-end პროგრამირება, შპს სქილვილი.

**ავტორი:** [სახელი გვარი]
**GitHub:** https://github.com/andrianager/cafe-project

## 1. პროექტის აღწერა

Cafe Aroma არის ერთგვერდიანი ვებსაიტი ყავახანისთვის. საიტზე არის მთავარი ბანერი, ინფორმაცია ყავახანის შესახებ, ფოტო-სლაიდერი, მენიუს ბარათები და საკონტაქტო ფორმა. საიტი მუშაობს მობილურზე, პლანშეტზე და კომპიუტერზე.

## 2. გამოყენებული ტექნოლოგიები

| ტექნოლოგია | რისთვის გამოვიყენე |
|---|---|
| HTML5 | გვერდის სემანტიკური სტრუქტურა (`header`, `nav`, `main`, `section`, `article`, `footer`) |
| CSS3 | ვიზუალური სტილი, Flexbox (ჰედერი, ფორმა), Grid (მენიუს ბარათები), `@media` რესპონსივობისთვის |
| JavaScript | მობილურის მენიუ, ფოტო-სლაიდერი, საკონტაქტო ფორმა |
| Git / GitHub | ვერსიების კონტროლი და კოდის შენახვა |
| VS Code + Live Server | კოდის წერა და შედეგის ნახვა |
| Squoosh | ფოტოების ოპტიმიზაცია |

cafe-project/

├── script.js       ინტერაქტიული ელემენტები

## 4. ფუნქციონალი

- **მენიუ:** მობილურზე ☰ ღილაკი ხსნის და ხურავს ნავიგაციას.
- **სლაიდერი:** ისრებით (❮ ❯) იცვლება 3 ფოტო.
- **ფორმა:** სახელის, ელ-ფოსტის, სასმელის არჩევისა და შეტყობინების შევსების შემდეგ გამოჩნდება მადლობის შეტყობინება.
- **რესპონსივობა:** დესკტოპზე 3 ბარათი ერთ რიგშია, პლანშეტზე 2, მობილურზე 1.

პროექტი ინდივიდუალურია, ამიტომ ყველა როლს ერთი პირი ასრულებს:

- **დიზაინერი:** ფერებისა და განლაგების არჩევა
- **დეველოპერი:** HTML, CSS და JavaScript კოდის წერა
- **ტესტერი:** საიტის შემოწმება სხვადასხვა ეკრანის ზომაზე
- **დოკუმენტატორი:** README-სა და პრეზენტაციის მომზადება

## 9. ოპტიმიზაცია

- **ფოტოები:** `coffee.jpg` 4 მბ-დან დაახლოებით 58 კბ-მდე, `croissant.jpg` 3,6 მბ-დან დაახლოებით 33 კბ-მდე დავაპატარავე (სიგანე 900 პიქსელი, MozJPEG, ხარისხი 75). სულ ფოტოები 8 მბ-დან დაახლოებით 0,7 მბ-მდე შემცირდა.
- **`loading="lazy"`:** მეორე და მესამე ფოტო მხოლოდ საჭიროების დროს იტვირთება.
- **`width` და `height`:** ფოტოებს ზომები აქვს მითითებული, რომ გვერდმა ჩატვირთვისას არ "ახტუნაოს".
- **`alt`:** ყველა ფოტოს აქვს აღწერა.
- **კოდი:** CSS და JavaScript ცალკე ფაილებშია, ამიტომ ბრაუზერი მათ ინახავს და ხელახლა არ იტვირთავს.
